Project overview

This project is a notebook-based data analysis case where the goal was to explore data, identify patterns, and communicate practical insights. The notebook combines data preparation, exploratory analysis, and result interpretation in one reproducible workflow.

Key goals

  • Clean and structure raw data for analysis
  • Investigate trends and relationships in the dataset
  • Present findings clearly for non-technical stakeholders

Methods used

  • Python and Jupyter Notebook workflow
  • Data wrangling and exploratory data analysis
  • Visual communication of key observations

Value delivered

  • Converted unstructured analysis into clear evidence
  • Highlighted actionable patterns in the data
  • Demonstrated analytical thinking and communication skills

Why this project matters

The Vitber project shows how I approach real-world analytical problems: framing the question, validating data quality, and turning findings into concrete recommendations. It reflects both technical execution and business understanding.
